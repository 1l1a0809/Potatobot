## Summary

Complete implementation of 3 major features:

## 1. Clans (Кланы/Команды)
- Full clan system: create, join, leave, management
- Roles: owner, officer, member
- Clan leaderboards with total kg tracking
- Member contribution tracking per clan
- Invites system with accept/decline
- Ownership transfer, disband, kick, leave
- Clan info UI with interactive callbacks
- Database: clans, clan_members, clan_invites tables + users.clan_id FK

## 2. ML Recommendations (ML Рекомендации)
- Personalized recommendation engine based on user behavior analysis
- User profiling: favorite hour/day, avg kg/dig, streak, clan status, achievements
- 5 recommendation types:
  - **dig_time**: Optimal dig time based on history
  - **clan**: Join/create clan suggestions
  - **achievement**: Next achievements to unlock with progress
  - **strategy**: Digging strategy tips
  - **social**: Invite friends, share achievements
- Smart caching with 1-hour TTL
- `/recommend` command with interactive UI
- Profile view `/recommend` → Profile button
- Smart notification hooks for inactive users

## 3. Chaos Engineering
- 7 experiment types:
  - **latency_injection**: Inject artificial latency
  - **error_injection**: Inject random errors
  - **db_connection_failure**: Simulate DB failure
  - **redis_connection_failure**: Simulate Redis failure
  - **partial_outage**: Combined latency + errors
  - **resource_exhaustion**: High latency simulation
  - **network_partition**: DB + Redis failure
- 7 predefined templates + custom experiments
- Admin-only: `/chaos`, `/chaos_custom`
- Interactive dashboard with templates
- Custom experiments: `/chaos_custom latency 2000 60`
- Async execution with metrics before/after
- Results analysis with observations
- Injection middleware for latency/error/DB/Redis failures
