## Configuration

The following secrets need to be configured:

1. **Bot Token**: Create a secret with your Telegram bot token
   ```bash
   kubectl create secret generic {{ include "potatobot.fullname" . }}-secrets \
     --from-literal=bot-token="YOUR_BOT_TOKEN" \
     --from-literal=database-url="postgresql://user:pass@host:5432/db" \
     --from-literal=admin-user-ids="123456789,987654321" \
     --from-literal=admin-session-secret="$(openssl rand -hex 32)"
   ```

2. **Database**: The chart includes a PostgreSQL subchart. Configure the password:
   ```bash
   kubectl create secret generic {{ include "potatobot.fullname" . }}-postgres \
     --from-literal=postgres-password="YOUR_PASSWORD"
   ```
