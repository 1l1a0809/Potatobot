feat: complete feature set with Redis, monitoring, admin panel, achievements, daily bonus, Web App, and Helm chart

## Features Added

### Core Infrastructure
- Redis integration: caching, rate limiting, sessions, daily bonus tracking, anti-cheat
- Structured logging with structlog + Sentry error tracking
- Prometheus metrics with DAU/WAU/Retention, cache hit rates, DB latency
- Grafana dashboard + Prometheus alerts

### Game Features
- Daily bonus with streak system (up to 30 days, increasing rewards)
- 22 achievements across 5 categories (digging, weight, streaks, leaderboards, special)
- Anti-cheat system (min interval, max kg/hour checks)
- Onboarding flow for new users

### Admin Panel
- Web-based admin panel at /admin/
- User management (list, detail, ban/unban)
- Real-time statistics (DAU, WAU, MAU, retention, cache hit rate)
- Health checks at /health, /ready

### Telegram Features
- Inline mode for digging from any chat
- Callback buttons for interactive UI (dig, stats, leaderboards, daily, achievements)
- Web App support (/app command)
- Deep linking for referrals

### API & Monitoring
- REST API at /api/v1/ for frontend integration
- Prometheus metrics at /metrics
- Prometheus alerts for: bot down, high errors, DB issues, low retention, etc.
- Grafana dashboard with 12 panels

### DevOps
- Database partitioning migration for dig_history (monthly partitions)
- Helm chart with: HPA, NetworkPolicy, PDB, ServiceMonitor, PrometheusRule
- k6 load test script
- Multi-stage Dockerfile with non-root user
- docker-compose with PostgreSQL + Redis
